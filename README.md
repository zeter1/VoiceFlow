# VoiceFlow

**VoiceFlow** — офлайн-приложение для голосового ввода текста в Windows на Python и `faster-whisper`. Оно слушает микрофон, локально распознаёт речь и вставляет подтверждённые фрагменты прямо в то поле ввода, которое находится в фокусе.

Программа не требует API-ключ OpenAI для распознавания речи и после загрузки модели выполняет транскрибацию локально на компьютере.

## Скачать готовую Windows-версию

Готовая Windows-сборка с **`VoiceFlow.exe`** публикуется на странице [GitHub Releases](https://github.com/zeter1/VoiceFlow/releases) в portable-архиве `VoiceFlow-Windows-x64.zip`.

Распакуйте архив целиком и запускайте `VoiceFlow.exe`. Устанавливать Python и Python-зависимости проекта отдельно не нужно. Рядом с ZIP публикуется SHA-256.

> При первом использовании выбранная Whisper-модель загружается отдельно. Для NVIDIA GPU по-прежнему нужны совместимые драйвер, CUDA/cuDNN-компоненты; CPU-режим не требует NVIDIA.


## Что демонстрирует проект

- построение real-time speech pipeline с локальным распознаванием речи;
- работу `faster-whisper` в режимах CPU и NVIDIA CUDA;
- потоковую обработку аудио без ожидания конца всей диктовки;
- интеграцию с Windows: глобальные hotkeys, активное поле ввода, tray и автозапуск;
- координацию фоновых задач, очередей и пользовательского интерфейса;
- privacy-first подход: распознавание после загрузки модели выполняется локально;
- отдельную диагностику для hotkeys, записи, распознавания и вставки текста.

## Возможности

- локальное распознавание речи через `faster-whisper`;
- голосовой ввод в реальном времени;
- вставка текста в текущее активное поле ввода;
- переключение между приложениями во время одной сессии диктовки;
- настраиваемая глобальная горячая клавиша;
- выбор микрофона;
- режимы CPU и NVIDIA CUDA;
- выбор Whisper-модели и профиля качества/скорости;
- голосовые команды для пунктуации и редактирования;
- опциональная локальная коррекция текста через `language-tool-python`;
- нативная Windows-вставка с резервными методами;
- системный трей и фоновая работа;
- автозапуск через `HKCU\Run`;
- подробная диагностика горячих клавиш, записи, распознавания и вставки.

## Установка

1. Установите x64-версию Python 3.11–3.13 для Windows.
2. Скачайте проект через **Code → Download ZIP** или Git:

```bash
git clone https://github.com/zeter1/VoiceFlow.git
cd VoiceFlow
```

3. Создайте виртуальное окружение и установите зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip setuptools wheel
py -m pip install -r requirements.txt
```

Для ускорения на NVIDIA GPU рекомендуется актуальный драйвер NVIDIA и совместимая CUDA/cuDNN-конфигурация, описанная в документации проекта.

При первом использовании выбранная Whisper-модель может быть загружена автоматически.

## Запуск

```powershell
py voiceflow.py
```

## Как пользоваться

1. Запустите VoiceFlow.
2. В настройках выберите микрофон, модель Whisper и режим CPU или CUDA.
3. Установите курсор в любое поле ввода — например, в браузере, Telegram, ChatGPT, документе или редакторе кода.
4. Нажмите глобальную горячую клавишу. Для новой конфигурации базовое значение — Ctrl+Shift+Space; клавишу можно изменить в интерфейсе.
5. Говорите обычным голосом.
6. Стабильные распознанные фрагменты будут вставляться в активное поле по мере диктовки.
7. Можно переключиться в другое приложение или поле — следующие фрагменты пойдут уже туда.
8. Нажмите горячую клавишу повторно, чтобы остановить запись.

Программа специально не вставляет весь текст повторно после остановки, чтобы не дублировать уже отправленные фрагменты.

## Архитектура

Основной поток данных:

```text
microphone
   ↓
audio capture
   ↓
realtime buffering / worker queue
   ↓
faster-whisper inference
   ↓
stability + deduplication
   ↓
voice commands / cleanup
   ↓
Windows text insertion
   ↓
active application
```

Подробно границы подсистем, lifecycle диктовки, CPU/CUDA paths, deduplication и insertion layer описаны в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md). Для ChatGPT/Codex есть отдельная карта: [`AGENTS.md`](AGENTS.md) + [`docs/AI_CONTEXT.md`](docs/AI_CONTEXT.md) + [`docs/IMPORT_BOUNDARIES.md`](docs/IMPORT_BOUNDARIES.md).

## Конфиденциальность

После загрузки модели Whisper:

- распознавание выполняется локально;
- API-ключ OpenAI не требуется;
- записанное аудио не отправляется в OpenAI API;
- рабочие настройки и логи остаются на компьютере пользователя.

Перед публикацией диагностических файлов рекомендуется проверить, что они не содержат личный текст диктовки или другие пользовательские данные. Дополнительные рекомендации: [`SECURITY.md`](SECURITY.md).

## Рекомендуемые настройки

### NVIDIA GPU

- устройство: `cuda`;
- compute type: `int8_float16`;
- модель: `medium` или `large-v3`;
- язык: `ru` для русской диктовки;
- профиль: Balanced или Quality.

### CPU

- устройство: `cpu`;
- compute type: `int8`;
- модель: `small` или `base`;
- профиль: Balanced или Faster.

## Голосовые команды

Поддерживаются команды для точки, запятой, вопросительного и восклицательного знака, новой строки и абзаца, пробела и Tab, Backspace и удаления слова, отмены, выделения всего, копирования, вставки и сохранения, перемещения курсора и очистки строки или поля ввода.

## Диагностика

Для каждого запуска создаётся отдельная диагностическая папка:

```text
voiceflow_logs/run_YYYY-MM-DD_HH-MM-SS_PID/
```

Последняя сессия доступна через:

```text
voiceflow_logs/_last_run/
```

Диагностика разделена по областям: hotkeys, запись, потоковое распознавание, очереди задач, вставка текста, уведомления и общие ошибки.

## Настройки

Настройки сохраняются в:

```text
voiceflow_settings/settings.json
```

Пользовательские настройки и рабочие логи исключены из Git.

## Проверка проекта

```powershell
python -m compileall -q voiceflow.py voiceflow_app tests
python -m unittest discover -s tests -v
```

CI выполняет syntax/compile и offline repository-contract regression tests без загрузки Whisper-моделей, доступа к микрофону и инициализации CUDA.

## Ограничения и уровень проверки

- качество и задержка распознавания зависят от модели, CPU/GPU и аудиоустройства;
- CUDA path требует совместимой локальной NVIDIA/CUDA/cuDNN-конфигурации;
- вставка текста и глобальные hotkeys зависят от поведения конкретного Windows-приложения;
- CI не подтверждает работу реального микрофона, CUDA, tray, hotkeys и вставки в сторонние приложения — эти сценарии требуют runtime-проверки в Windows;
- `voiceflow.py` является тонким entrypoint; внутренняя реализация разделена по canonical owner-модулям, а `runtime.py` оставлен только как внешний compatibility facade.
