# Security and privacy

VoiceFlow работает с микрофоном, локальным распознаванием речи, буфером обмена, активными окнами Windows и автоматической вставкой текста. В этих сценариях могут обрабатываться личные данные.

## Сообщение об уязвимости

Если вы обнаружили проблему, которая может приводить к раскрытию диктуемого текста, неожиданной вставке данных, небезопасному доступу к устройствам или другим нежелательным системным действиям, не публикуйте чувствительные детали в открытом issue до предварительного контакта.

Связь: **zeter11@gmail.com**

Укажите версию проекта, Windows, CPU/CUDA-режим и минимальные шаги воспроизведения.

## Голосовые данные

После загрузки модели распознавание выполняется локально. Тем не менее пользователь сам отвечает за содержимое аудио и текста, который диктуется в приложения.

Не прикладывайте публично:

- записи реальных приватных разговоров;
- расшифровки с личными данными;
- тексты с паролями, токенами или секретами;
- логи, если в них присутствуют фрагменты диктовки.

Для воспроизведения проблемы лучше использовать искусственный тестовый текст.

## Диагностические файлы

Перед публикацией проверьте:

- распознанные фрагменты;
- пути к локальным файлам;
- имена устройств;
- сведения о Windows-профиле;
- другой пользовательский контекст.

Публикуйте только минимально необходимую часть диагностики.

## Локальная модель

`faster-whisper` может загрузить модель при первом использовании. После загрузки распознавание выполняется локально; VoiceFlow не требует OpenAI API key для транскрибации.
