VoiceFlow Offline — основные настройки
======================================

Режим редактирования:
- Точно как сказано — минимум правок, полезно для проверки качества Whisper.
- Чистый текст — обычный режим: убирает мусор, добавляет пунктуацию, исправляет часть ошибок.
- Деловой стиль — делает текст формальнее.
- Коротко — сокращает текст.
- Развернуто — расширяет текст.
- Продающий стиль — делает текст более продающим.
- Для ChatGPT / AI-промпт — оформляет речь как запрос для нейросети.
- Для кода — оформляет речь как техническую задачу.

Для диагностики плохого ввода лучше временно поставить “Точно как сказано”. Так можно понять: ошибся Whisper или испортила очистка текста.

Язык:
- auto — автоопределение;
- ru — русский;
- en — английский;
- es/fr/de — другие языки.

Если диктуешь в основном на русском, лучше ставить ru. Auto иногда может ошибаться на коротких фразах.

Privacy mode (WAV):
- удаляет временные WAV-файлы после обработки;
- текстовые логи всё равно могут содержать распознанный текст;
- перед отправкой логов проверь dictation_text.txt, если там есть личные данные.

Микрофон:
- выбирай реальный микрофон, в который говоришь;
- выбор применяется автоматически;
- если выбран не тот вход, программа может писать тишину или шум;
- при дальнем микрофоне слова чаще пропускаются.

Горячая клавиша:
- рекомендуемая: F9;
- запасной вариант: Ctrl+Shift+Space;
- не используй сочетания только из Ctrl/Shift/Alt/Win, например Ctrl+Win или Ctrl+Shift;
- такие сочетания на Windows могут срабатывать нестабильно.

Realtime-ввод текста:
- режим всегда “вставлять фрагментами”;
- финальная вставка после остановки отключена;
- текст вставляется туда, где сейчас курсор;
- можно менять окно во время записи.

Вставлять отредактированный текст:
- включено — вставляет cleaned_text с пунктуацией и правками;
- выключено — вставляет более сырой raw_text;
- если cleaner портит текст, временно выключи эту галочку.

Глубокая грамматика:
- включает дополнительные правила и LanguageTool, если установлен;
- может улучшить итоговый текст;
- но в realtime иногда лучше отключить, если важна скорость и меньше вмешательства.

Показывать уведомления:
- включает красный toast “Идёт запись”;
- уведомление не должно забирать фокус у активного окна;
- его можно перетаскивать.

Запускать при старте Windows 11:
- добавляет программу в автозагрузку через HKCU Run;
- при старте может открываться в фоне/трее.

Настройки хранятся рядом с программой:
voiceflow_settings/settings.json
