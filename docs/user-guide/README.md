# Пользовательские и обучающие инструкции VoiceFlow

Здесь собраны материалы для установки, настройки и повседневного использования программы. Инженерная документация и AI-карта находятся уровнем выше в docs/.

Рекомендуемый порядок:
1. `00 Оглавление.txt` — полный индекс материалов.
2. `01 Что делает программа.txt` — назначение VoiceFlow.
3. `02 Быстрый старт.txt` — первый запуск и диктовка.
4. `Установка всё что надо.txt` — окружение и зависимости.
5. Остальные файлы — настройка качества, CUDA, команды, логи, пунктуация, микрофон и tray.

Для разработчиков: [../ARCHITECTURE.md](../ARCHITECTURE.md), [../AI_CONTEXT.md](../AI_CONTEXT.md), [../DEVELOPMENT.md](../DEVELOPMENT.md).
