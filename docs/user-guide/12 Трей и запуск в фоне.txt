VoiceFlow Offline — трей и запуск в фоне
=======================================

VoiceFlow может работать в фоне через системный трей. Окно программы не обязано быть открытым, чтобы работала диктовка по F9.

Для трея нужны библиотеки:
pystray
pillow

Установка:
py -m pip install pystray pillow

Меню трея:
- Открыть окно;
- Скрыть окно;
- Начать / остановить запись;
- Выход.

Важно:
- команды из трея передаются через безопасную worker_queue главного Tk-потока;
- это нужно, чтобы меню трея не “теряло” нажатия;
- если меню трея не срабатывает, смотри worker_queue.jsonl и recording_state.jsonl.

Крестик окна:
- крестик может не закрывать программу полностью;
- он может скрывать окно в трей;
- программа продолжит работать в фоне;
- F9 будет продолжать работать.

Как полностью закрыть:
1. Найди значок VoiceFlow в трее.
2. Правый клик.
3. Выход.

Перед заменой voiceflow.py:
1. Обязательно выйди через трей → Выход.
2. Убедись, что в диспетчере задач не остался старый Python/VoiceFlow.
3. Замени voiceflow.py.
4. Запусти новую версию.

Если запущены две копии:
- горячие клавиши и уведомления могут вести себя странно;
- одна копия может ловить F9, другая показывать окно;
- логи могут попасть в разные папки;
- закрывай лишние копии.
