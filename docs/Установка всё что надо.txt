Установка всего, что нужно для VoiceFlow Offline
===============================================

1. Python
---------
Рекомендуется Python x64: 3.11 / 3.12 / 3.13.

Скачать:
https://www.python.org/downloads/windows/

При установке обязательно поставь галочку:
Add Python to PATH

Проверка:
py --version
python --version

2. Python-библиотеки
--------------------
Открой CMD или PowerShell и выполни:

py -m pip install --upgrade pip setuptools wheel
py -m pip install numpy sounddevice faster-whisper pyperclip pyautogui keyboard language-tool-python pystray pillow

Что за библиотеки:
- numpy — обработка аудио;
- sounddevice — запись микрофона;
- faster-whisper — локальное распознавание речи;
- pyperclip — буфер обмена;
- pyautogui — резервные клавиши и голосовые команды;
- keyboard — чтение горячих клавиш в некоторых режимах;
- language-tool-python — дополнительная грамматика;
- pystray — значок в трее;
- pillow — картинка значка для трея.

3. NVIDIA GPU / CUDA
--------------------
Если хочешь ускорение на NVIDIA:
- установи свежий NVIDIA Driver;
- установи CUDA Toolkit 12.x;
- установи cuDNN 9 для CUDA 12.x;
- добавь CUDA/cuDNN bin в PATH.

Проверка:
where cublas64_12.dll
where cudnn_ops64_9.dll

Если обе DLL находятся, GPU-режим вероятнее заработает.

4. Рекомендуемые настройки после установки
------------------------------------------
Для NVIDIA:
- Устройство: cuda;
- Compute: int8_float16;
- Модель: medium или large-v3;
- Язык: ru;
- Профиль realtime: Баланс или Качество;
- Интервал: 4–6 сек.

Для CPU:
- Устройство: cpu;
- Compute: int8;
- Модель: small/base;
- Профиль realtime: Баланс или Быстрее.

5. Проверка микрофона
---------------------
В программе нажми “Обновить” рядом с микрофоном и выбери нужный вход.

Если текста нет:
- выбран не тот микрофон;
- микрофон слишком далеко;
- Windows не даёт доступ к микрофону;
- в системе выбран другой input;
- программа запущена без нужных прав.

6. Правильный запуск
--------------------
Запуск:
py voiceflow.py

Если горячая клавиша или вставка в некоторые приложения не работает, попробуй запуск от имени администратора.

7. Обновление программы
-----------------------
Перед заменой voiceflow.py:
1. Закрой VoiceFlow через трей → Выход.
2. Замени файл.
3. Запусти заново.

Настройки сохраняются в:
voiceflow_settings/settings.json

Логи сохраняются в:
voiceflow_logs/_last_run/
