# Поддержка и диагностика

Если VoiceFlow работает не так, как ожидается, создайте GitHub Issue через форму **Сообщить об ошибке**. Хороший отчёт должен позволять воспроизвести проблему без публикации лишних пользовательских данных.

## Что указать

- commit/версию приложения;
- версию Windows;
- CPU или NVIDIA CUDA;
- Whisper model и compute type;
- используемый микрофон, если проблема связана с записью;
- точные шаги воспроизведения;
- ожидаемое и фактическое поведение;
- небольшой релевантный фрагмент diagnostics.

## Где искать диагностику

Последняя сессия доступна в:

```text
voiceflow_logs/_last_run/
```

Логи разделены по hotkeys, recording, streaming/inference, worker queue, insertion и notifications. Обычно полезнее приложить только относящиеся к проблеме файлы, а не весь каталог.

Перед публикацией удалите личный текст диктовки и другие данные, которыми не хотите делиться.

## Быстрая проверка репозитория

```powershell
python -m compileall -q voiceflow.py tests
python -m unittest discover -s tests -v
```

Эти проверки намеренно не загружают Whisper-модель, не инициализируют CUDA и не используют реальный микрофон. Проблемы, зависящие от audio device, GPU, hotkeys или активного Windows-приложения, требуют runtime-проверки на Windows.
